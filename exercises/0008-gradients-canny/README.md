# 第 08 课独立练习：梯度、Sobel 与 Canny

先阅读 [课程](../../lessons/0008-gradients-canny.html)，关闭答案后独立完成。已有 case08 是受控演示，不是本题提交物。

## 任务
生成先升后降的三角斜坡，输出 CV_32F 的 Gx、Gy 和幅值；对有噪声矩形比较有无预平滑的 Canny，并记录边缘数量变化。

## 交付与验收
提交你自己的 C++ 实现、明确输入、逐步数值预测、实际值和差值；保存关键中间 PNG。内部上升段 Gx=80、下降段 Gx=-80、Gy=0；常量图边缘数零。报告负响应不能仅提交绝对值图。

至少加入正常输入、最小或常量输入、参数错误三组测试。所有 I/O 检查错误；新增源码显式加入你自己的 CMake 目标。写明算法假设与一个不满足假设的失败案例。

评分为数值 40、边界与错误处理 20、原理与失败解释 20、可复现性 20。达到 80 分并核对关键数值后，自述仍不确定的一点。禁止把参考程序退出码零等同于独立掌握。

对照演示：`foundation_labs 08 build/lab-output/08`，或 `./scripts/RunLab.ps1 -Lesson 08`。
