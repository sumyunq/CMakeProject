# 第 04 课独立练习：图像算术与直方图

先阅读 [课程](../../lessons/0004-arithmetic-histogram.html)，关闭答案后独立完成。已有 case04 是受控演示，不是本题提交物。

## 任务
生成 [0,0,100,200,255]，分别进行加三十、减三十以及浮点往返，手写五个非零直方图箱的预期，比较均衡化前后累计分布。

## 交付与验收
提交你自己的 C++ 实现、明确输入、逐步数值预测、实际值和差值；保存关键中间 PNG。加三十得到 [30,30,130,230,255]；原始直方图 h(0)=2，其余指定箱各一，总和五。8 位往返末点变为 225，证明不可逆。

至少加入正常输入、最小或常量输入、参数错误三组测试。所有 I/O 检查错误；新增源码显式加入你自己的 CMake 目标。写明算法假设与一个不满足假设的失败案例。

评分为数值 40、边界与错误处理 20、原理与失败解释 20、可复现性 20。达到 80 分并核对关键数值后，自述仍不确定的一点。禁止把参考程序退出码零等同于独立掌握。

对照演示：`foundation_labs 04 build/lab-output/04`，或 `./scripts/RunLab.ps1 -Lesson 04`。
