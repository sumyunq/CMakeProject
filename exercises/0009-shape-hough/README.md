# 第 09 课独立练习：轮廓、连通域与 Hough

先阅读 [课程](../../lessons/0009-shape-hough.html)，关闭答案后独立完成。已有 case09 是受控演示，不是本题提交物。

## 任务
生成两个斜角接触的小方块，分别做四连通和八连通，并生成有孔矩形比较 RETR_EXTERNAL 与 RETR_TREE。为长直线加入缺口，研究 maxLineGap。

## 交付与验收
提交你自己的 C++ 实现、明确输入、逐步数值预测、实际值和差值；保存关键中间 PNG。斜角接触在四连通为两个前景域，在八连通为一个；有孔图必须记录层级关系，面积统计时明确是否扣孔，不能直接把所有绝对轮廓面积相加。

至少加入正常输入、最小或常量输入、参数错误三组测试。所有 I/O 检查错误；新增源码显式加入你自己的 CMake 目标。写明算法假设与一个不满足假设的失败案例。

评分为数值 40、边界与错误处理 20、原理与失败解释 20、可复现性 20。达到 80 分并核对关键数值后，自述仍不确定的一点。禁止把参考程序退出码零等同于独立掌握。

对照演示：`foundation_labs 09 build/lab-output/09`，或 `./scripts/RunLab.ps1 -Lesson 09`。
