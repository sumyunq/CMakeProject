# 第 07 课独立练习：形态学与结构元素

先阅读 [课程](../../lessons/0007-morphology.html)，关闭答案后独立完成。已有 case07 是受控演示，不是本题提交物。

## 任务
在矩形内部挖一个单像素孔，外部添加一个单像素亮点；分别比较开、闭及先开后闭，报告目标面积和连通域数量。

## 交付与验收
提交你自己的 C++ 实现、明确输入、逐步数值预测、实际值和差值；保存关键中间 PNG。原始面积仍为一千二百：少一个内部点、多一个外部点。开运算移除孤点但孔周围结果要实际计数；闭运算应填孔，不能把两者作用互换。

至少加入正常输入、最小或常量输入、参数错误三组测试。所有 I/O 检查错误；新增源码显式加入你自己的 CMake 目标。写明算法假设与一个不满足假设的失败案例。

评分为数值 40、边界与错误处理 20、原理与失败解释 20、可复现性 20。达到 80 分并核对关键数值后，自述仍不确定的一点。禁止把参考程序退出码零等同于独立掌握。

对照演示：`foundation_labs 07 build/lab-output/07`，或 `./scripts/RunLab.ps1 -Lesson 07`。
