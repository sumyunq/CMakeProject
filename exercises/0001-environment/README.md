# 练习 0001：证明环境正确

不修改全局 PATH，不改原 Qt/OpenCV 安装。

1. 按 README 独立完成两种配置，记录实际运行的命令与诊断输出。
2. 写清 Qt、OpenCV 头文件、OpenCV DLL、编译器及运行库各自来源。
3. 解释 CMake 找包失败、链接失败、启动缺 DLL 的区别。
4. 在单独的临时部署副本移走一个 OpenCV DLL，观察启动错误，然后还原副本。禁止在原安装目录操作。
5. 运行部署验证，说明它证明了什么、尚未证明什么。

在本目录自行创建环境报告，完成后对照[参考解答](../../solutions/0001-environment/README.md)自行复盘。验收要求：能从实际证据解释依赖来源；不以“能运行”代替所有版本证据。无需等待会话验收才能继续。
