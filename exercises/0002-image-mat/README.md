# 练习 0002：预测共享与复制

自行创建练习源码，参考mat_demo的构建方式，为自己的练习添加独立目标；不加入默认演示目标。完成后再看[单独参考解答](../../solutions/0002-image-mat/README.md)，无需等待会话解锁。

任务：
1. 构造 4×6、CV_8UC1 父图，选择便于手算且不同于教材的数据。
2. 创建宽度小于父图、至少两行的 ROI，以及浅拷贝、clone。
3. 在运行前写预测表：尺寸、行步长、连续性、修改会影响谁。
4. 分别修改 ROI、浅拷贝和独立副本，验证预测。
5. 用逐行访问求 ROI 像素和，与 cv::sum 对比；解释为什么不能假定它连续。
6. 构造一个错误假设，用实际输出推翻它，避免执行越界或悬空访问。

验收：源码能构建；预测和实际结果有对照；能解释 row/col 与 x/y 区别、每像素字节数、数据生命周期。不要只复制现成示例的输出。
