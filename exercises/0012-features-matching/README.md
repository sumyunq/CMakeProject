# 第 12 课独立练习：特征、描述与匹配

先阅读 [课程](../../lessons/0012-features-matching.html)，关闭答案后独立完成。已有 case12 是受控演示，不是本题提交物。

## 任务
独立写去均值 NCC，在 [1,2,3] 和 [11,12,13]、反序 [3,2,1]、常量 [5,5,5] 上测试；再将场景旋转并记录固定块方法的失败。

## 交付与验收
提交你自己的 C++ 实现、明确输入、逐步数值预测、实际值和差值；保存关键中间 PNG。前两个块相关为一，反序为负一，常量必须报告不可判定；对精确裁剪的非平坦块定位误差为零。提交次佳峰排除策略及理由。

至少加入正常输入、最小或常量输入、参数错误三组测试。所有 I/O 检查错误；新增源码显式加入你自己的 CMake 目标。写明算法假设与一个不满足假设的失败案例。

评分为数值 40、边界与错误处理 20、原理与失败解释 20、可复现性 20。达到 80 分并核对关键数值后，自述仍不确定的一点。禁止把参考程序退出码零等同于独立掌握。

对照演示：`foundation_labs 12 build/lab-output/12`，或 `./scripts/RunLab.ps1 -Lesson 12`。
