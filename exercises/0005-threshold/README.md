# 第 05 课独立练习：阈值分割与光照

先阅读 [课程](../../lessons/0005-threshold.html)，关闭答案后独立完成。已有 case05 是受控演示，不是本题提交物。

## 任务
独立生成左右亮度不同的背景，并画相同深色方块。比较固定、Otsu、自适应三种掩码，记录真阳性和误检像素，不允许仅凭视觉选择。

## 交付与验收
提交你自己的 C++ 实现、明确输入、逐步数值预测、实际值和差值；保存关键中间 PNG。边界测试 [39,40,41] 在 T=40、BINARY 下应为 [0,0,255]；三种算法的正确性应分别对照你生成的真值掩码，报告交并比。

至少加入正常输入、最小或常量输入、参数错误三组测试。所有 I/O 检查错误；新增源码显式加入你自己的 CMake 目标。写明算法假设与一个不满足假设的失败案例。

评分为数值 40、边界与错误处理 20、原理与失败解释 20、可复现性 20。达到 80 分并核对关键数值后，自述仍不确定的一点。禁止把参考程序退出码零等同于独立掌握。

对照演示：`foundation_labs 05 build/lab-output/05`，或 `./scripts/RunLab.ps1 -Lesson 05`。
