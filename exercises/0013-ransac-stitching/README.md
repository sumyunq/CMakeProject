# 第 13 课独立练习：RANSAC、配准与拼接

先阅读 [课程](../../lessons/0013-ransac-stitching.html)，关闭答案后独立完成。已有 case13 是受控演示，不是本题提交物。

## 任务
独立增加三组离群点，比较全体均值、中位位移及共识估计；把其中一组换成仿射位移，分析纯平移残差随位置变化。提供阈值敏感性表和失败案例。

## 交付与验收
提交你自己的 C++ 实现、明确输入、逐步数值预测、实际值和差值；保存关键中间 PNG。当前数据应恰好四内点二外点，重估 (7,5.025)；阈值小于零点一时可能拆散共识，阈值过大会收进离群点。你应报告误差而不是承诺所有数据都成功。

至少加入正常输入、最小或常量输入、参数错误三组测试。所有 I/O 检查错误；新增源码显式加入你自己的 CMake 目标。写明算法假设与一个不满足假设的失败案例。

评分为数值 40、边界与错误处理 20、原理与失败解释 20、可复现性 20。达到 80 分并核对关键数值后，自述仍不确定的一点。禁止把参考程序退出码零等同于独立掌握。

对照演示：`foundation_labs 13 build/lab-output/13`，或 `./scripts/RunLab.ps1 -Lesson 13`。
