# 第 10 课独立练习：距离变换与分水岭

先阅读 [课程](../../lessons/0010-watershed.html)，关闭答案后独立完成。已有 case10 是受控演示，不是本题提交物。

## 任务
改为一大一小两个接触圆，分别尝试全局峰值比例和局部极大值种子，比较过分割、漏检。提交种子图、最终标签及每个标签面积。

## 交付与验收
提交你自己的 C++ 实现、明确输入、逐步数值预测、实际值和差值；保存关键中间 PNG。背景距离零；两个种子中心在传播后保持各自标签；边界存在负一。独立任务必须明确种子生成规则及至少一个失败参数，而不只保存彩色结果。

至少加入正常输入、最小或常量输入、参数错误三组测试。所有 I/O 检查错误；新增源码显式加入你自己的 CMake 目标。写明算法假设与一个不满足假设的失败案例。

评分为数值 40、边界与错误处理 20、原理与失败解释 20、可复现性 20。达到 80 分并核对关键数值后，自述仍不确定的一点。禁止把参考程序退出码零等同于独立掌握。

对照演示：`foundation_labs 10 build/lab-output/10`，或 `./scripts/RunLab.ps1 -Lesson 10`。
