# 第 03 课独立练习：像素遍历与颜色空间

先阅读 [课程](../../lessons/0003-pixels-color.html)，关闭答案后独立完成。已有 case03 是受控演示，不是本题提交物。

## 任务
独立生成 5×8 彩色图，每列红通道为 10x，取 Rect(2,1,3,2)，用行指针求和，并转换灰度。要求同时测试 clone 后的连续矩阵及原 ROI，不能把实验的常量图直接复制交差。

## 交付与验收
提交你自己的 C++ 实现、明确输入、逐步数值预测、实际值和差值；保存关键中间 PNG。红通道和应为 2×(20+30+40)=180；逐像素检查两种遍历所得结果相同，父图 ROI 外部不变。

至少加入正常输入、最小或常量输入、参数错误三组测试。所有 I/O 检查错误；新增源码显式加入你自己的 CMake 目标。写明算法假设与一个不满足假设的失败案例。

评分为数值 40、边界与错误处理 20、原理与失败解释 20、可复现性 20。达到 80 分并核对关键数值后，自述仍不确定的一点。禁止把参考程序退出码零等同于独立掌握。

对照演示：`foundation_labs 03 build/lab-output/03`，或 `./scripts/RunLab.ps1 -Lesson 03`。
