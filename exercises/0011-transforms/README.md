# 第 11 课独立练习：仿射、透视与插值

先阅读 [课程](../../lessons/0011-transforms.html)，关闭答案后独立完成。已有 case11 是受控演示，不是本题提交物。

## 任务
生成棋盘，先平移再旋转，比较连续两次变换与组合矩阵一次变换；另建一张类别值为零和十的标签图，对比最近邻与线性插值的唯一值集合。

## 交付与验收
提交你自己的 C++ 实现、明确输入、逐步数值预测、实际值和差值；保存关键中间 PNG。单位变换的最大绝对差应为零；整数平移、最近邻且不裁剪时面积保持。组合顺序需要明确列向量约定，后执行矩阵左乘。

至少加入正常输入、最小或常量输入、参数错误三组测试。所有 I/O 检查错误；新增源码显式加入你自己的 CMake 目标。写明算法假设与一个不满足假设的失败案例。

评分为数值 40、边界与错误处理 20、原理与失败解释 20、可复现性 20。达到 80 分并核对关键数值后，自述仍不确定的一点。禁止把参考程序退出码零等同于独立掌握。

对照演示：`foundation_labs 11 build/lab-output/11`，或 `./scripts/RunLab.ps1 -Lesson 11`。
