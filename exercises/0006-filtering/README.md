# 第 06 课独立练习：卷积、滤波与边界

先阅读 [课程](../../lessons/0006-filtering.html)，关闭答案后独立完成。已有 case06 是受控演示，不是本题提交物。

## 任务
用七乘七常量图和中心脉冲分别比较三乘三及五乘五均值，手算角点和中心。再用非对称核 [-1,0,1] 验证相关的正负方向。

## 交付与验收
提交你自己的 C++ 实现、明确输入、逐步数值预测、实际值和差值；保存关键中间 PNG。三乘三常量角点在零边界为四十，在反射边界为九十；三乘三脉冲均值中心约二十八。方向响应应在浮点或有符号矩阵中比较。

至少加入正常输入、最小或常量输入、参数错误三组测试。所有 I/O 检查错误；新增源码显式加入你自己的 CMake 目标。写明算法假设与一个不满足假设的失败案例。

评分为数值 40、边界与错误处理 20、原理与失败解释 20、可复现性 20。达到 80 分并核对关键数值后，自述仍不确定的一点。禁止把参考程序退出码零等同于独立掌握。
