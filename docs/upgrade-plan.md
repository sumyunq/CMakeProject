# OpenCV 学习工程升级计划

## 目标与约束

一次交付专业术语、课程深度、真实数据实验、构建与自动化验证四项改进。完整教材继续开放，学习进度由学习者自己的练习决定。

固定 Qt 6.8.3、OpenCV 5.0.0、C++20、MSVC 14.44.35207、CMake 3.30.5、Ninja 1.12.1、spdlog 1.17.0；不修改全局 PATH 或原有依赖安装。每批前更新会话记录；验收后中文提交并推送当前远程分支 feat/opencv-learning。

## 实施内容

1. **全部术语**：盘点30课和现有词表，按概念和领域拆分同词异义，保留已有31条；每条提供词性、推荐译法、定义、语境、易混义、双语例句、版本、来源和校核状态。以CSV维护并生成或同步Markdown；未获权威中文来源确认的译名标为项目推荐。
2. **高级课程**：完善配准、标定、视频跟踪、工业测量、DNN、性能和综合项目的推导、可运行原生示例、中间结果、失败案例、独立练习、答案和验收指标。增加完整图像处理工作台参考实现，工业检测和视频AI提供可运行参考流程及数据契约。答案不进入默认构建，实机实验与合成验证分开。
3. **真实数据**：将许可明确的小型彩色和灰度样本、由样本生成的短视频与标注纳入仓库；首选scikit-image的astronaut图像。ONNX Model Zoo的SqueezeNet 1.1模型按需下载到忽略目录；逐项记录来源、固定版本、许可、SHA-256、输入输出契约和局限。校验或下载失败明确退出；样本离线可用，模型下载后推理离线可用。
4. **构建与自动化**：保留本机预设；补充干净Windows准备、预检、构建、运行和部署说明。GitHub Actions托管运行器检查文档、术语、样本和脚本；完整编译仅显式手动触发具备固定工具链的自托管运行器。未配置时报告未执行，不能将文档检查冒充编译通过。

## 测试与验收

- Debug、Release完整构建与CTest；独立参考答案两种配置通过；新增接口测正常、边界、错误输入和资源生命周期。
- 原生扩展验证真实图像读写、配准、视频读取和ONNX CPU推理，记录模型哈希、输入输出形状、固定输入结果与容差。
- 真实样本记录输入、标注、参数、预期指标、失败案例与复现命令，单样本结果不代表生产精度。
- 校验全部术语必填字段、概念ID、CSV/Markdown一致性、来源和本地链接，逐课检查例句和语境。
- 验证干净PATH的Release部署；没有第二台干净Windows机器时保留可执行步骤并标记未验证。
- 运行wbliu-code-check；不可用则记录并按规范自检；未经手动触发不运行qt-cpp-review。
- 最终报告通过项、未验证项、实际提交和推送结果；依赖源码、构建缓存、本机路径和日志不入提交。

## 默认决定

- 全部四项实施，不等待逐课验收；示例通过不代表学习者掌握。
- 小样本入库，模型从固定地址下载并校验哈希；许可证不明的资源不分发。
- 依赖保持锁定。确有不兼容时记录原因与替代方案，不把替代实验冒充真实验证。
- 完成后推送feat/opencv-learning，不合并到其他分支。
