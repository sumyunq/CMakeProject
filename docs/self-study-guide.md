# 不依赖会话的完整自学指南

本课程的终点是能独立实现、解释、验证并部署视觉应用。全部教材、练习和参考解答随工程提供；不需要等代理解锁下一课，也不要求把作业发回会话才能继续。

## 第一次打开

1. 打开 [课程入口](../lessons/index.html)，按 01～30 顺序阅读；已经掌握的内容可用本课自测和验收决定是否跳过。
2. 按 [README](../README.md) 构建固定环境。先完成 01、02，再运行 `./scripts/RunLab.ps1 -Lesson 03`；03～30 用同一入口改变编号。
3. 图片、中间结果与报告默认写入忽略提交的 `build/lab-output/local-debug/编号`。程序的通过结果只是参考演示符合契约，不是你已经完成作业。
4. 练习位于 `exercises/编号-主题/README.md`，答案在单独的 `solutions/编号-主题/README.md`。先做预测再看答案；参考数值取决于相应数据与参数，不要把答案中的数字套到自己的图像。
5. 每课建立自己的学习报告。下面有可复制模板；学习状态保存在 [progress.md](../learning-records/progress.md)，你可以直接手动修改。

答案默认不参与演示构建。需要核对答案代码时，可单独运行 `./scripts/CheckReferenceAnswers.ps1 -Configuration Debug`，或选择Release；它从答案文档直接提取C++片段，编译并执行数值和边界测试，不以另一份手抄实现冒充答案验证。

## 每课的闭环

### 阅读和预测

先回答“输入是什么，输出是什么，怎样算错”。写出至少一个数值预测，例如：ROI 行步长、阈值后前景面积、变换后坐标、相机距离变化造成的视差。再看推导，把公式中的每个量写上单位、形状和坐标系。

### 观察实验

运行对应实验并保留终端输出和中间图。按“输入 → 每一步中间结果 → 最终结果”检查。看起来合理不等于正确；用已知真值、手算小矩阵、统计量或重投影误差判断。

### 独立实现

更改尺寸、噪声、目标位置或参数后完成本课任务。不要只执行原例。记录一项正常输入、一项边界输入、一项算法不适用输入。禁止通过实际执行越界或释放后访问来制造失败；用输入校验和安全构造的反例观察契约。

自己的练习建议在对应练习目录下创建 `.cpp`，在根 CMake 显式新增独立目标并链接 `application_runtime`、`business` 和实际用到的 OpenCV 库。不要把练习源文件直接加入已有 main 目标；多份 main 会产生链接冲突。模仿三个实验目标的组织方式即可，不需要重新配置全局 PATH。

### 对答案和自验收

完成后再打开参考解答。允许实现不同，判断条件是相同契约、可复现指标和正确解释。必须能说明：为什么选这个算法，参数改变会怎样，什么输入会失败，怎样检测失败。失败时按照 [排错指南](troubleshooting.md) 找层次，而不是反复随机调整参数。

## 验收评分

每课 100 分：原理和预测 20、独立实现 30、指标与测试 25、失败分析 15、复盘与复现步骤 10。建议达到 80 分再进入强依赖后续课。以下任一项未满足时保持“进行中”或“待复习”：

- 访问可能越界、内存生命周期不清楚、错误被静默吞掉。
- 无法解释坐标、类型、单位、数据布局，或者训练与测试数据混用。
- 只有截图而没有运行方法、输入与参数；只在训练样例上调到好看。
- 综合项目在退出、输入失败或队列过载时挂起，或者宣称达到未经测量的精度。

这个门槛是学习建议，不是教材访问限制。可以继续往后读，再回来补薄弱项。

“已自验收”可以在进度表的证据栏记录；如果由外部评审确认，再记录“已验收”。没有必要为了记录状态回到本会话。

## 三种实验层级

| 层级 | 能证明什么 | 不能替代什么 |
|---|---|---|
| 默认离线实验 | 数学、像素、数据契约、合成输入上的算法行为 | 真实相机和复杂真实数据效果 |
| 原生扩展实验 | OpenCV 完整模块 API、生成视频的读写、极小 ONNX 图的加载与推理 | 任意第三方检测模型、相机驱动和 GPU |
| 自己的真实项目 | 指定硬件、数据集、模型及部署机器上的指标 | 未测试环境与全部视觉任务 |

默认实验无网络、摄像头和模型下载需求。原生扩展依赖首次准备需要网络；完成源码构建与本地 ONNX 生成后也可离线运行。见 [原生模块实验](native-labs.md)。硬件实验提前列出了输入条件、采集方法、指标与验收，设备到位后可自行执行，不需要再等教材。

## 路线与里程碑

- 01～03：解释图像字节布局、所有权、颜色与显示。
- 04～10：构造和比较图像处理、计数、分割流程。
- 11～15：实现配准、标定与三维数值实验，解释误差与退化。
- 16～20：理解时间、运动、成像条件、工业测量和缺陷指标。
- 21～23：区分训练与推理，验证预处理、张量、坐标还原和输出指标。
- 24～27：测量性能，正确处理线程、退出、部署和源码阅读。
- 28～30：用三个综合项目把以上知识整合，每个项目保留测试集、参数与验收报告。

## 最终毕业条件

三个综合项目都应提供源码、可复现构建、固定数据、参数文件、正常/边界/失败测试、结果报告和部署目录。隔一周拿未见数据重新测一次；能定位数据、算法、模型、线程或部署哪一层出了问题，并说明不能解决的情况，才算达到独立开发目标。不要把通读 30 页或记住 API 名称当作完成学习。

复习时参考 [数学速查](math-reference.md)、[关键算法纵深研读](algorithm-deep-dive.md)、[英文词汇](qt-opencv-vocabulary.md) 与 [4/5 迁移](opencv5-migration.md)。纵深研读补充采样、Otsu、特征描述、平面标定、LK、Kalman、SVM/逻辑回归、CNN和误差传播推导。后续遇到新算法可按第 27 课的方法自主查固定版本源码和论文。
