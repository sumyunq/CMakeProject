# 视觉学习工程排错指南

## 从最早失败的一层开始

| 现象 | 收集证据 | 排查顺序 | 成功判据 |
|---|---|---|---|
| CMake 找不到依赖 | 首条 configure 错误、本机预设、安装目录 | 实际 CMake 版本 → 精确库版本 → 对应配置路径 | 配置成功且报告固定版本 |
| 编译找不到头文件 | include 名、安装的头文件树 | 检查 4/5 模块名 → target 链接依赖 → 完整模块是否安装 | 不靠全局 include 路径通过 |
| unresolved external symbol | 完整符号、链接命令 | 是否漏源文件、漏 target_link_libraries、配置/架构混用 | 干净构建也链接通过 |
| 启动缺 DLL | 程序路径、当前配置、依赖目录 | 用脚本启动 → Debug/Release DLL → Qt 平台插件 → 重新部署 | 仅系统 PATH 的副本可启动 |
| OpenCV assertion failed | 首个断言、函数、输入元数据 | empty → dims → type/depth/channels → size/ROI → 参数范围 | 输入违反契约时能明确拒绝 |
| 红蓝颠倒、颜色发灰 | 已知纯色块及像素数值 | BGR/RGB → alpha → 位深/归一化 → 显示格式 | 已知测试图逐点匹配 |
| ROI 第一行对，后面错 | step、elemSize、cols、isContinuous | 是否按紧密内存遍历；改逐行 ptr | 与支持步长的 OpenCV 算法一致 |
| 显示偶发花屏 | Mat/QImage 所有权、线程关系 | 外部缓冲区释放 → 写入并发 → 深复制/不可变快照 | 源销毁/修改后输出仍有效 |
| 阈值不稳定 | 原图、直方图、光照条件 | 输入值域 → 光照/反光 → 全局/局部阈值 → 失败检测 | 留出数据误检漏检可度量 |
| 轮廓面积和像素面积不同 | 二值掩膜、contourArea、countNonZero | 连通像素定义与几何边界定义是否混淆 | 指标定义与验收口径一致 |
| 配准得到离谱矩阵 | 匹配图、内点、重投影误差 | 描述子距离类型 → 重复纹理 → 退化点分布 → RANSAC阈值 | 留出点误差和内点分布均合格 |
| 标定误差小但测量不准 | 标定图分布、留出图、尺度单位 | 数据泄漏 → 角点覆盖 → 模型不适用 → 镜头/焦距变化 | 独立尺度件误差达标 |
| 跟踪越跑越慢 | 帧时间戳、队列长度、处理耗时 | 输入速率 → 无界队列 → 日志/拷贝 → 丢旧帧/背压策略 | 队列有界，p95延迟可控 |
| ONNX 读入失败 | 模型哈希、opset、首个不支持算子 | 先跑生成的 ReLU 模型 → 模型契约 → 支持算子/形状 → 后端 | 不能用空 catch 或跳过推理算成功 |
| 推理框错位 | resize比例、padding、坐标单位 | RGB/BGR → NCHW/NHWC → normalization → 坐标逆变换 | 已知坐标测试能精确还原 |
| GPU 比 CPU 慢 | 含传输的端到端耗时 | 小任务启动开销 → 内存往返 → 同步点 → batch | 同一精度下比较预热后分位延迟 |
| 退出卡死 | 线程状态、队列、取消标志 | 锁内等待 → 生产者未停止 → 未唤醒条件变量 → join顺序 | 空闲/满载/取消均可限时退出 |

## 最小复现步骤

把真实输入缩成非正方形、不同通道值的小图，保留触发条件。记录编译配置、版本、随机种子、输入形状与类型、调用参数。先禁用 UI 和并行，确认数值，再逐层恢复。若替换成合成数据不再失败，应比较输入契约而不是立刻归咎于库。

## 不靠猜测的调参

先固定一个验证集，再每次只改一类参数。保留参数扫描表：值、误差、误检漏检、耗时。选在多个输入上有稳定区间的值，避免为了单图把阈值调到极端。算法不满足成像假设时，换成像条件或方法，比继续堆形态学有效。

## 遇到教材之外的问题

1. 沿第 27 课的调用链查固定版本声明、实现和测试。
2. 搜索完整错误和 API 名，先读官方文档、源码 issue 与论文；注意 4.x/5.x 差异。
3. 提取最小复现，写下当前假设及能推翻它的实验。
4. 确认根因后添加一个回归测试，并把边界记录进自己的报告。

无需为了继续下一课解决所有扩展硬件问题；默认合成实验是可独立完成的共同基线。
