梯度、Sobel 与 Canny

边缘是亮点还是变化？

问题与直觉

边缘表示空间强度变化，均匀白墙内部不应有边缘。梯度有大小和方向，大小说明变化强度，方向指向灰度增长最快的位置。Sobel 在一方向做差分，另一方向做平滑，因此比简单相邻相减更抗噪，但其响应幅值带有核增益。先保存有符号响应再转换显示，才能判断亮到暗和暗到亮的方向。

数学与手算

对每列递增十的斜坡，三乘三 Sobel 横向核 [-1,0,1] 与纵向 [1,2,1] 外积，内部响应为 (右−左)×4=20×4=80。默认反射边界使第一列的左右采样相同，响应零。若直接把响应存为 8U，下降沿的负值会被截去，导致一侧边缘消失。

完整最小实验

./scripts/RunLab.ps1 -Lesson 08
# 或在构建输出目录直接调用，输出目录可自行指定
foundation_labs 08 build/lab-output/08

完整可编译入口在 FoundationLabs.cpp 的 case08，共享 main 负责日志、参数检查、目录创建和异常转非零退出码。该实验自行构造输入，不需要下载图片、摄像头或模型。先查看该函数及其调用的 save、require，再运行；不要只抄一个脱离初始化和错误处理的 API 片段。

case08 保存 sobel.png、canny.png，断言斜坡内部八十、边界零及常量图 Canny 无边缘。Canny 的流程是梯度、非极大值抑制、双阈值和滞后连接；本实验由调用者决定是否额外做高斯平滑。低阈值决定弱候选，高阈值决定强种子，弱边只有连接强边才保留。

预测后运行并核对标准输出的数值与中间 PNG。程序断言失败、目录不可写或图像编码失败均返回非零；尝试把课号写成 99，确认入口拒绝无效范围。输出目录必须可创建且可写，不能把已有普通文件当目录。最小实验验证了受控输入的行为，不等于已经验证所有真实业务图像。

失败案例与排错

失败实验：高纹理背景会产生比目标更强的梯度，调高阈值可能连真实低对比目标一起删除。两个阈值不是二值分割中的前景亮度阈值。边缘图通常有一像素宽的曲线，也不等于封闭可填充掩码。

排错顺序是先确认输入尺寸、类型、通道语义和取值范围，再检查中间矩阵，最后调整算法参数。把每一步输出与未处理原图并排比较，记录参数及观察结论。显示器自动缩放、JPEG 压缩、归一化和伪彩都会改变观感；判断像素值应读取矩阵，不能从截图颜色反推数值。

独立练习

生成先升后降的三角斜坡，输出 CV_32F 的 Gx、Gy 和幅值；对有噪声矩形比较有无预平滑的 Canny，并记录边缘数量变化。

验收标准

内部上升段 Gx=80、下降段 Gx=-80、Gy=0；常量图边缘数零。报告负响应不能仅提交绝对值图。

提交输入生成规则、运行命令、至少一个数值表、全部关键中间结果和失败案例。评分：数值正确四十分，边界与错误处理二十分，解释参数和失败原因二十分，可复现记录二十分。八十分且所有关键数值正确算完成本课；能够口头解释为什么成立，比把测试标绿更重要。

自测：先回答再展开

亮墙为什么没边缘？

空间导数为零。

负梯度去了哪里？

若使用 8U 会饱和到零，应保留有符号中间结果。

弱边缘一定删除吗？

连接到强种子的弱边可以保留。
