距离变换与分水岭

相互接触的零件怎样分开？

问题与直觉

简单连通域会把接触物体当作一个对象。距离变换给每个非零像素赋到最近零像素的距离，物体内部常出现峰值。用峰值建立种子，再使用分水岭扩展标签，可以在同一前景区域内形成多个对象。距离大意味着远离背景，不等于物体中心的语义识别；长条或不规则物体可能有多处峰值。

数学与手算

一维前景 [0,1,1,1,0] 的最近背景距离为 [0,1,2,1,0]。二维欧氏距离是 sqrt(dx²+dy²)，和曼哈顿距离 |dx|+|dy| 不同。本课两个半径二十三的圆相距二十七像素，因此连成一体；各圆心距离背景大于二十。背景标记一、两个对象种子标记二和三、未知区零，分水岭完成后边界为负一。

完整可编译入口在 FoundationLabs.cpp 的 case10，共享 main 负责日志、参数检查、目录创建和异常转非零退出码。该实验自行构造输入，不需要下载图片、摄像头或模型。先查看该函数及其调用的 save、require，再运行；不要只抄一个脱离初始化和错误处理的 API 片段。

case10 输出 touching.png、distance.png、watershed.png。距离显示图仅把浮点距离缩放到零至二百五十五；数值检查直接读取原距离。实验使用人工放置的可验证种子，目的是把种子生成错误与分水岭传播错误分开观察，并不声称完成自动计数。

预测后运行并核对标准输出的数值与中间 PNG。程序断言失败、目录不可写或图像编码失败均返回非零；尝试把课号写成 99，确认入口拒绝无效范围。输出目录必须可创建且可写，不能把已有普通文件当目录。最小实验验证了受控输入的行为，不等于已经验证所有真实业务图像。

失败案例与排错

失败实验：把所有非零区域预先标记成同一个标签，就没有未知区域可以分成两个对象；一个对象内放多个种子则容易过分割。阈值取最大距离的固定比例可能把大小差别很大的物体的小目标完全丢掉。输入 marker 必须是有符号 32 位标签图，不能用 8 位显示图替代。

排错顺序是先确认输入尺寸、类型、通道语义和取值范围，再检查中间矩阵，最后调整算法参数。把每一步输出与未处理原图并排比较，记录参数及观察结论。显示器自动缩放、JPEG 压缩、归一化和伪彩都会改变观感；判断像素值应读取矩阵，不能从截图颜色反推数值。

独立练习

改为一大一小两个接触圆，分别尝试全局峰值比例和局部极大值种子，比较过分割、漏检。提交种子图、最终标签及每个标签面积。

验收标准

背景距离零；两个种子中心在传播后保持各自标签；边界存在负一。独立任务必须明确种子生成规则及至少一个失败参数，而不只保存彩色结果。

提交输入生成规则、运行命令、至少一个数值表、全部关键中间结果和失败案例。评分：数值正确四十分，边界与错误处理二十分，解释参数和失败原因二十分，可复现记录二十分。八十分且所有关键数值正确算完成本课；能够口头解释为什么成立，比把测试标绿更重要。
