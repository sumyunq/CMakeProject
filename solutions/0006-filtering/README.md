# 第 06 课参考解答：卷积、滤波与边界

## 推导与正确结果
均值三乘三核的每个权重为九分之一。全图九十时内部均值九十；左上角零填充只有四个有效像素，所以输出 4×90/9=40。反射边界仍然是九十。默认三乘三高斯核可写为 [1,2,1] 的外积除十六，单个二百五十五脉冲的中心输出约 63.75，量化后六十四；同一脉冲经过三乘三中值为零。

## 独立题解法
任务：用七乘七常量图和中心脉冲分别比较三乘三及五乘五均值，手算角点和中心。再用非对称核 [-1,0,1] 验证相关的正负方向。

先按输入生成规则建立真值表，再依次计算本课算子；保留浮点或有符号中间结果，显示副本与计算矩阵分开。对每个预期数值使用断言，误差是浮点时给出容差及单位，整数计数则要求精确相等。独立题的关键结果：三乘三常量角点在零边界为四十，在反射边界为九十；三乘三脉冲均值中心约二十八。方向响应应在浮点或有符号矩阵中比较。

## 逐步独立实现提示
常量九十，五乘五零边界角点只有九个有效点，得到 9*90/25=32.4，8 位舍入约 32；反射仍为九十。五乘五均值的中心脉冲为 255/25≈10。用 [-1,0,1] 对升序 [10,20,30] 做相关，中心为二十；若翻转成卷积则为负二十。边缘处须单独注明使用哪一种外推。

## 调试提示与失败解释
失败实验：一条只有一像素宽的亮线被中值滤波完全删除，不能说所有孤立结构都是噪声。均值对椒盐噪声会把极值扩散到邻居。高斯降低高频噪声，也降低细纹对比；应根据需要保留的最小结构决定平滑尺度。
若数值不符，依次检查类型、坐标顺序、边界模式与参数；读取矩阵原值，不用显示归一化结果代替计算值。运行无效课号必须非零退出，输出路径错误也必须显式失败。
