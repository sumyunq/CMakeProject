# 第 07 课参考解答：形态学与结构元素

## 推导与正确结果
本课前景矩形宽四十、高三十，面积一千二百。三乘三方形腐蚀使四边各缩一像素，得到 38×28=1064；膨胀得到 42×32=1344。开运算先腐蚀后膨胀，可以清除离矩形很远的孤立亮点，矩形恢复一千二百。闭运算顺序相反，适合填小暗孔和连接窄缝。

## 独立题解法
任务：在矩形内部挖一个单像素孔，外部添加一个单像素亮点；分别比较开、闭及先开后闭，报告目标面积和连通域数量。

先按输入生成规则建立真值表，再依次计算本课算子；保留浮点或有符号中间结果，显示副本与计算矩阵分开。对每个预期数值使用断言，误差是浮点时给出容差及单位，整数计数则要求精确相等。独立题的关键结果：原始面积仍为一千二百：少一个内部点、多一个外部点。开运算移除孤点但孔周围结果要实际计数；闭运算应填孔，不能把两者作用互换。

## 逐步独立实现提示
先保留无孔矩形真值副本，内部挖孔、远处加亮点。对 noisy 分别 morphologyEx OPEN/CLOSE，并逐点与真值比较。开运算的腐蚀会扩大暗孔，之后膨胀不一定恢复角点，因此不应预设开运算后的面积为 1199；先输出差分位置，再解释结构元素如何影响孔角。先开后闭适合同时抑制这两种小扰动，但合法细结构可能被删除。

## 调试提示与失败解释
失败实验：把相距两像素的零件做闭运算，它们可能粘为一个连通域，计数错误。开运算也会删除合法细线。重复执行腐蚀不是只改变灰度，它会持续缩小目标；测量前处理如果改变外边界，需要标定这一系统偏差。
若数值不符，依次检查类型、坐标顺序、边界模式与参数；读取矩阵原值，不用显示归一化结果代替计算值。运行无效课号必须非零退出，输出路径错误也必须显式失败。
