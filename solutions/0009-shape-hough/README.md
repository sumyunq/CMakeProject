# 第 09 课参考解答：轮廓、连通域与 Hough

## 推导与正确结果
宽四十高三十的实心矩形有 40×30=1200 个前景像素；外轮廓经过边缘像素中心，四角坐标跨度是三十九和二十九，面积为 39×29=1131。这个差值不是 OpenCV 算错。连通域返回值包含背景，因此单矩形返回二；全黑图仍有背景标签零，返回一。

## 独立题解法
任务：生成两个斜角接触的小方块，分别做四连通和八连通，并生成有孔矩形比较 RETR_EXTERNAL 与 RETR_TREE。为长直线加入缺口，研究 maxLineGap。

先按输入生成规则建立真值表，再依次计算本课算子；保留浮点或有符号中间结果，显示副本与计算矩阵分开。对每个预期数值使用断言，误差是浮点时给出容差及单位，整数计数则要求精确相等。独立题的关键结果：斜角接触在四连通为两个前景域，在八连通为一个；有孔图必须记录层级关系，面积统计时明确是否扣孔，不能直接把所有绝对轮廓面积相加。

## 逐步独立实现提示
构造两个 2×2 方块，第二块左上角放在第一块右下角的斜下一点，确保只角接触。connectedComponents 指定 connectivity=4 和 8，返回值分别应为三和二，均含背景。有孔矩形用 RETR_TREE，读取 hierarchy 的 child/parent 而不是猜数组顺序；前景像素面积用 countNonZero 作为独立对照。

## 可运行参考与区别
项目内 `src/app/FoundationLabs.cpp` 的 `case09` 提供完整实验入口，可运行 `foundation_labs 09 build/lab-output/09` 或 `./scripts/RunLab.ps1 -Lesson 09`。
case09 调用 connectedComponentsWithStats、findContours、contourArea、HoughLinesP。component.png 是面积对照，line.png 在 y=40 从 x=10 到 85 画直线。Hough 把候选边缘投票到参数空间，直线常写为 ρ=x cosθ+y sinθ；概率版本返回有限线段端点。检查至少一条线段，不依赖其输出排序。
该程序演示课程基准输入；独立题改变了数据或评估要求，必须另写生成规则和检查，不能直接提交基准截图。

## 调试提示与失败解释
失败实验：将面积阈值一千一百五十用于轮廓面积会误删该矩形，而用于像素面积会保留。Hough 的阈值过低会在噪声中检出很多线；最大间隙过大可能连接不同零件的共线边缘。单位像素的长度尚不是毫米。
若数值不符，依次检查类型、坐标顺序、边界模式与参数；读取矩阵原值，不用显示归一化结果代替计算值。运行无效课号必须非零退出，输出路径错误也必须显式失败。
