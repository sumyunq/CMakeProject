# 第 11 课参考解答：仿射、透视与插值

## 推导与正确结果
平移矩阵 [[1,0,7],[0,1,5]] 将 (24,24) 映射到 (31,29)。warpAffine 默认接收源到目标矩阵，内部反向采样避免空洞；设置 WARP_INVERSE_MAP 后矩阵意义反过来。线性插值以小数位置周围像素加权，例如一维 [0,100] 在 0.25 位置为 25；最近邻只取一个样本。

## 独立题解法
任务：生成棋盘，先平移再旋转，比较连续两次变换与组合矩阵一次变换；另建一张类别值为零和十的标签图，对比最近邻与线性插值的唯一值集合。

先按输入生成规则建立真值表，再依次计算本课算子；保留浮点或有符号中间结果，显示副本与计算矩阵分开。对每个预期数值使用断言，误差是浮点时给出容差及单位，整数计数则要求精确相等。独立题的关键结果：单位变换的最大绝对差应为零；整数平移、最近邻且不裁剪时面积保持。组合顺序需要明确列向量约定，后执行矩阵左乘。

## 逐步独立实现提示
将二维仿射补成三乘三齐次矩阵，先执行平移 T 后执行旋转 R 的组合为 R*T。同一输出画布上比较两步 warp 与一步组合 warp 的绝对差，差异来自重复采样及中间裁剪，不能把差异归因于矩阵乘法不准确。标签图最近邻结果唯一值只能是零和十；线性插值在非整数映射边界可能出现中间值，枚举唯一值证明。

## 调试提示与失败解释
失败实验：把四个透视点按不同顺序传入，输出会扭曲甚至翻折。三个仿射点共线会导致退化，四个透视点也需要非退化布局。多次连续 warp 会反复插值导致模糊，应该先组合矩阵后尽量只采样一次。
若数值不符，依次检查类型、坐标顺序、边界模式与参数；读取矩阵原值，不用显示归一化结果代替计算值。运行无效课号必须非零退出，输出路径错误也必须显式失败。
