# 第 05 课参考解答：阈值分割与光照

## 推导与正确结果
BINARY 的规则是 I>T 才输出 maxValue，等于阈值仍属于背景。[0,40,40,200,200,255] 在 T=40 时输出三个前景。Otsu 最大化 w0w1(μ0−μ1)²，其中 w 是两组占比，μ 是各组均值。对这个小数组，选择 40 能把暗组和亮组分开。算法返回的阈值与输出掩码是两件不同的结果，都应保存记录。

## 独立题解法
任务：独立生成左右亮度不同的背景，并画相同深色方块。比较固定、Otsu、自适应三种掩码，记录真阳性和误检像素，不允许仅凭视觉选择。

先按输入生成规则建立真值表，再依次计算本课算子；保留浮点或有符号中间结果，显示副本与计算矩阵分开。对每个预期数值使用断言，误差是浮点时给出容差及单位，整数计数则要求精确相等。独立题的关键结果：边界测试 [39,40,41] 在 T=40、BINARY 下应为 [0,0,255]；三种算法的正确性应分别对照你生成的真值掩码，报告交并比。

## 逐步独立实现提示
背景设左半部 100、右半部 220，两个方块都比当地背景暗四十，真值为两个矩形。暗前景使用 BINARY_INV。固定阈值无法同时完全分开 60/100 和 180/220；先列出这四种灰度再证明不存在一个同时合适的阈值。用奇数窗口大于笔画宽度、C 为正值做局部分割，分别统计 TP、FP、FN，再算 TP/(TP+FP+FN)。

## 调试提示与失败解释
失败实验：在白纸上叠加由左至右的渐变光照，固定阈值会使一侧字迹消失；把自适应窗口设得比笔画还小，则阈值跟随笔画本身，产生碎边。噪声很多时先适度平滑再分割，但要观察最细笔画是否也被滤掉。
若数值不符，依次检查类型、坐标顺序、边界模式与参数；读取矩阵原值，不用显示归一化结果代替计算值。运行无效课号必须非零退出，输出路径错误也必须显式失败。
