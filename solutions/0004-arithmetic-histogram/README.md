# 第 04 课参考解答：图像算术与直方图

## 推导与正确结果
输入 [0,10,250,255] 加二十后，8 位输出 [20,30,255,255]，浮点输出 [20,30,270,275]。两个高亮像素在饱和后不可区分，后来减二十也无法恢复。直方图 h(k) 是等于灰度 k 的像素数，概率 p(k)=h(k)/N；累计分布是前面各箱之和。四个输入像素总计数必须为四，这比只看曲线形状更可靠。

## 独立题解法
任务：生成 [0,0,100,200,255]，分别进行加三十、减三十以及浮点往返，手写五个非零直方图箱的预期，比较均衡化前后累计分布。

先按输入生成规则建立真值表，再依次计算本课算子；保留浮点或有符号中间结果，显示副本与计算矩阵分开。对每个预期数值使用断言，误差是浮点时给出容差及单位，整数计数则要求精确相等。独立题的关键结果：加三十得到 [30,30,130,230,255]；原始直方图 h(0)=2，其余指定箱各一，总和五。8 位往返末点变为 225，证明不可逆。

## 逐步独立实现提示
原始直方图只有四个非零箱：0 的计数二、100/200/255 各一。加三十再减三十后得到 [0,0,100,200,225]，末点误差三十；浮点过程中不裁剪则全部恢复。均衡化可用 equalizeHist，对累计分布先减最小非零累计数再归一到 255，预测映射 0→0、100→85、200→170、255→255，并实际核对量化。

## 调试提示与失败解释
失败实验：把直方图上界设为 255，会遗漏最大值。另一个典型问题是逐帧独立均衡化造成视频闪烁；相同物体受当前帧整体灰度分布影响而变化。全局均衡化并不保证保留测量的物理亮度关系，CLAHE 则要额外记录网格和裁剪参数。
若数值不符，依次检查类型、坐标顺序、边界模式与参数；读取矩阵原值，不用显示归一化结果代替计算值。运行无效课号必须非零退出，输出路径错误也必须显式失败。
