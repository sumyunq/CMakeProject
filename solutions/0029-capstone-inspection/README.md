# 综合项目二：工业测量与缺陷检验：完整参考解答

## 解题思路与实现

参考答案：先threshold定位最大主体，以boundingRect左上点估计平移并将待检件平移回参考坐标；对齐后在内部ROI做absdiff并threshold，连通域面积≥10记缺陷。计量使用主体外框，缺陷判断使用内部孔洞，避免同一统计混为一谈。里程碑一生成数据与真值；二测量和比例输入校验；三平移配准和UNKNOWN；四缺陷过滤与混淆矩阵；五Qt报告视图、CSV和部署。生产版使用标定板、畸变矫正和重复性实验，记录测量不确定度。

## 数值推导

标定比例s=已知毫米/对应像素；宽度L=s×w。40像素、0.1mm/px得到4mm。完整40×20矩形面积800；挖掉4×5内孔得到780，参考异或缺陷20像素。仅平移1像素的完整件与参考异或出现两条20像素边带，共40像素，数量反而比真实缺陷更大。

## 独立扩展的实施顺序

项目规格：输入参考件和待检件、标尺点、ROI、定位结果、缺陷表及CSV报告。验收集含20张正常、20张4×5缺孔、20张x方向±1..3px偏移正常件，固定生成种子。正常拒判不能算合格；定位失败必须标UNKNOWN并计入独立指标。合成图对齐后的误报0、漏报0、宽误差≤0.1mm；实拍阈值需另做标注和标定。

## 逐项验收

60张真值与混淆矩阵30分、配准负例20分、毫米误差与比例检查20分、UNKNOWN及导出15分、GUI和部署15分。≥80且合成漏报必须0；真实工业精度需另附实拍证据。

## 自测详解

1. 漏报率分母是什么？实际缺陷件数。2. 外框面积等于材料面积吗？不等，孔洞不改变外框。3. 比例误差1%怎样传播？4mm宽约产生0.04mm系统误差，不能靠更多像素平均消除。

## 配准与指标参考算例

对二值参考图求boundingRect为(20,20,40,20)，待测正常件向右移3px得到(23,20,40,20)。因此tx=20-23=-3，ty=0。使用2×3仿射矩阵[1,0,tx;0,1,ty]和INTER_NEAREST，BORDER_CONSTANT=0对齐，之后xor为全0。内孔件仍保持外框(20,20,40,20)，配准不会抹去孔洞，xor面积20。若外框尺寸改变或主体缺失，返回UNKNOWN，不能强行把任意图对齐后判良。

对60张验收集：实际缺陷20、实际正常40；期望TP=20、FN=0、FP=0、TN=40、UNKNOWN=0。Precision=TP/(TP+FP)=1，Recall=TP/(TP+FN)=1，不能用总体准确率掩盖稀少缺陷的漏报。ROI内宽度由外框40px乘0.1得到4mm；标定尺度必须大于0且有限。空输入、尺度0、多个同面积主体均有明确失败原因。

CSV参考字段为image_id,status,width_px,scale_mm_per_px,width_mm,defect_pixels,defect_count,registration_dx,registration_dy。数值以固定locale写出，路径/错误检查失败不能生成“已成功导出”的UI状态。实拍验证还需同一件重复测量30次报告标准差，并用已知量块校验系统偏差。
