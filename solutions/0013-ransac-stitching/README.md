# 第 13 课参考解答：RANSAC、配准与拼接

## 推导与正确结果
本课位移为 (7,5)、(7.1,5)、(6.9,5)、(7,5.1)、(40,-20)、(-30,60)。以欧氏距离零点五为阈值，前四个形成共识，重估均值为 (7,5.025)。全部平均却得到约 (6.33,10.017)，显著偏离真值。对于随机采样，成功概率 p 与内点率 w、最小样本数 s 关系为 N≥log(1−p)/log(1−w^s)。

## 独立题解法
任务：独立增加三组离群点，比较全体均值、中位位移及共识估计；把其中一组换成仿射位移，分析纯平移残差随位置变化。提供阈值敏感性表和失败案例。

先按输入生成规则建立真值表，再依次计算本课算子；保留浮点或有符号中间结果，显示副本与计算矩阵分开。对每个预期数值使用断言，误差是浮点时给出容差及单位，整数计数则要求精确相等。独立题的关键结果：当前数据应恰好四内点二外点，重估 (7,5.025)；阈值小于零点一时可能拆散共识，阈值过大会收进离群点。你应报告误差而不是承诺所有数据都成功。

## 逐步独立实现提示
对每个位移作为候选，计算所有位移到它的欧氏距离，将小于阈值的点加入候选集合，保留最大集合并计算均值，平票时记录歧义。对新增离群组重复计算全体平均、中位与共识误差。仿射情形位移随 x,y 变化，不再是常数，因此残差会呈空间趋势。画残差与坐标关系比单个平均误差更能暴露模型不足；正式 RANSAC 还需随机采样终止与退化检查。

## 可运行参考与区别
项目内 `src/app/FoundationLabs.cpp` 的 `case13` 提供完整实验入口，可运行 `foundation_labs 13 build/lab-output/13` 或 `./scripts/RunLab.ps1 -Lesson 13`。

## 调试提示与失败解释
失败实验：若所有错误匹配也形成更大的相干位移群，最大共识会选择错误目标。若把透视变化交给平移模型，即使阈值放宽也只能掩盖模型错误。内点全部集中于小角落时，外推到远处仍可能严重失真。
若数值不符，依次检查类型、坐标顺序、边界模式与参数；读取矩阵原值，不用显示归一化结果代替计算值。运行无效课号必须非零退出，输出路径错误也必须显式失败。
