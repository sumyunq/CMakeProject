# 第 08 课参考解答：梯度、Sobel 与 Canny

## 推导与正确结果
对每列递增十的斜坡，三乘三 Sobel 横向核 [-1,0,1] 与纵向 [1,2,1] 外积，内部响应为 (右−左)×4=20×4=80。默认反射边界使第一列的左右采样相同，响应零。若直接把响应存为 8U，下降沿的负值会被截去，导致一侧边缘消失。

## 独立题解法
任务：生成先升后降的三角斜坡，输出 CV_32F 的 Gx、Gy 和幅值；对有噪声矩形比较有无预平滑的 Canny，并记录边缘数量变化。

先按输入生成规则建立真值表，再依次计算本课算子；保留浮点或有符号中间结果，显示副本与计算矩阵分开。对每个预期数值使用断言，误差是浮点时给出容差及单位，整数计数则要求精确相等。独立题的关键结果：内部上升段 Gx=80、下降段 Gx=-80、Gy=0；常量图边缘数零。报告负响应不能仅提交绝对值图。

## 逐步独立实现提示
对列值 0,10,20,30,40,30,20,10,0 构造每行相同的图。三乘三 Sobel 在未接触峰值的上升段为八十，下降段负八十，峰值处因左右相等为零。Gy 全零。先记录梯度原值，再 convertScaleAbs 做显示。固定随机种子加入噪声，分别直接 Canny 和 GaussianBlur 后 Canny；不能预先保证所有参数下边缘数都减少，应记录实测结果及目标边界保留程度。

## 可运行参考与区别
项目内 `src/app/FoundationLabs.cpp` 的 `case08` 提供完整实验入口，可运行 `foundation_labs 08 build/lab-output/08` 或 `./scripts/RunLab.ps1 -Lesson 08`。
case08 保存 sobel.png、canny.png，断言斜坡内部八十、边界零及常量图 Canny 无边缘。Canny 的流程是梯度、非极大值抑制、双阈值和滞后连接；本实验由调用者决定是否额外做高斯平滑。低阈值决定弱候选，高阈值决定强种子，弱边只有连接强边才保留。
该程序演示课程基准输入；独立题改变了数据或评估要求，必须另写生成规则和检查，不能直接提交基准截图。

## 调试提示与失败解释
失败实验：高纹理背景会产生比目标更强的梯度，调高阈值可能连真实低对比目标一起删除。两个阈值不是二值分割中的前景亮度阈值。边缘图通常有一像素宽的曲线，也不等于封闭可填充掩码。
若数值不符，依次检查类型、坐标顺序、边界模式与参数；读取矩阵原值，不用显示归一化结果代替计算值。运行无效课号必须非零退出，输出路径错误也必须显式失败。
