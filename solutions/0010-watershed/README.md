# 第 10 课参考解答：距离变换与分水岭

## 推导与正确结果
一维前景 [0,1,1,1,0] 的最近背景距离为 [0,1,2,1,0]。二维欧氏距离是 sqrt(dx²+dy²)，和曼哈顿距离 |dx|+|dy| 不同。本课两个半径二十三的圆相距二十七像素，因此连成一体；各圆心距离背景大于二十。背景标记一、两个对象种子标记二和三、未知区零，分水岭完成后边界为负一。

## 独立题解法
任务：改为一大一小两个接触圆，分别尝试全局峰值比例和局部极大值种子，比较过分割、漏检。提交种子图、最终标签及每个标签面积。

先按输入生成规则建立真值表，再依次计算本课算子；保留浮点或有符号中间结果，显示副本与计算矩阵分开。对每个预期数值使用断言，误差是浮点时给出容差及单位，整数计数则要求精确相等。独立题的关键结果：背景距离零；两个种子中心在传播后保持各自标签；边界存在负一。独立任务必须明确种子生成规则及至少一个失败参数，而不只保存彩色结果。

## 逐步独立实现提示
先生成真值两个圆的独立标签，再计算合并二值掩码及距离图。全局阈值如 0.7*maxDistance 会漏掉峰值不足的大圆相对小目标；局部极大值可用距离图与膨胀距离图相等得到候选，但平台区域必须合并。去除噪声候选后连通域产生种子，从一开始区分背景、未知和目标编号，最后评价与真值的重叠及种子数量。

## 可运行参考与区别
项目内 `src/app/FoundationLabs.cpp` 的 `case10` 提供完整实验入口，可运行 `foundation_labs 10 build/lab-output/10` 或 `./scripts/RunLab.ps1 -Lesson 10`。
case10 输出 touching.png、distance.png、watershed.png。距离显示图仅把浮点距离缩放到零至二百五十五；数值检查直接读取原距离。实验使用人工放置的可验证种子，目的是把种子生成错误与分水岭传播错误分开观察，并不声称完成自动计数。
该程序演示课程基准输入；独立题改变了数据或评估要求，必须另写生成规则和检查，不能直接提交基准截图。

## 调试提示与失败解释
失败实验：把所有非零区域预先标记成同一个标签，就没有未知区域可以分成两个对象；一个对象内放多个种子则容易过分割。阈值取最大距离的固定比例可能把大小差别很大的物体的小目标完全丢掉。输入 marker 必须是有符号 32 位标签图，不能用 8 位显示图替代。
若数值不符，依次检查类型、坐标顺序、边界模式与参数；读取矩阵原值，不用显示归一化结果代替计算值。运行无效课号必须非零退出，输出路径错误也必须显式失败。
