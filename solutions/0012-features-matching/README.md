# 第 12 课参考解答：特征、描述与匹配

## 推导与正确结果
归一化互相关 NCC 对每个块减均值，再计算点积除以两者范数。块 [1,2,3] 与 [11,12,13] 去均值后相同，相关系数为一，因此可抵抗不发生饱和的亮度偏移。平坦块去均值后全零，分母为零，没有辨识度；应该先检查标准差并拒绝，而不是相信某个库实现给出的特殊分值。

## 独立题解法
任务：独立写去均值 NCC，在 [1,2,3] 和 [11,12,13]、反序 [3,2,1]、常量 [5,5,5] 上测试；再将场景旋转并记录固定块方法的失败。

先按输入生成规则建立真值表，再依次计算本课算子；保留浮点或有符号中间结果，显示副本与计算矩阵分开。对每个预期数值使用断言，误差是浮点时给出容差及单位，整数计数则要求精确相等。独立题的关键结果：前两个块相关为一，反序为负一，常量必须报告不可判定；对精确裁剪的非平坦块定位误差为零。提交次佳峰排除策略及理由。

## 逐步独立实现提示
手写 NCC：检查两向量长度一致且非空，求均值，逐项累加 da*db、da²、db²，若任一平方和为零返回不可判定；否则返回 numerator/sqrt(energyA*energyB)。同序去均值向量均为 [-1,0,1]，分子二、分母二，所以一；反序分子负二，所以负一。匹配场景时滑窗执行同一计算，与 matchTemplate 对照，屏蔽最佳位置周围至少模板半宽的邻域后再找次佳峰。

## 调试提示与失败解释
失败实验：重复棋盘产生很多同等好的峰；旋转九十度或改变尺度会破坏固定块对应。最大得分高不意味着唯一，应比较次佳峰并屏蔽最佳峰邻域，避免把同一峰周围像素当独立竞争者。匹配还应经过几何一致性验证。
若数值不符，依次检查类型、坐标顺序、边界模式与参数；读取矩阵原值，不用显示归一化结果代替计算值。运行无效课号必须非零退出，输出路径错误也必须显式失败。
