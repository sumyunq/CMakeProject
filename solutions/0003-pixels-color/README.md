# 第 03 课参考解答：像素遍历与颜色空间

## 推导与正确结果
灰度是通道的加权组合而不是平均值。对于 B=10,G=20,R=30，使用约 0.114B+0.587G+0.299R 得到 21.85，8 位结果为 22。实验取父图六列中的三列、两行作为 ROI，红通道总和为 2×3×30=180。每行有效字节只有九个，而父图每行占十八个字节；把六个像素作为连续数组读取会跨入 ROI 外部。

## 独立题解法
任务：独立生成 5×8 彩色图，每列红通道为 10x，取 Rect(2,1,3,2)，用行指针求和，并转换灰度。要求同时测试 clone 后的连续矩阵及原 ROI，不能把实验的常量图直接复制交差。

先按输入生成规则建立真值表，再依次计算本课算子；保留浮点或有符号中间结果，显示副本与计算矩阵分开。对每个预期数值使用断言，误差是浮点时给出容差及单位，整数计数则要求精确相等。独立题的关键结果：红通道和应为 2×(20+30+40)=180；逐像素检查两种遍历所得结果相同，父图 ROI 外部不变。

## 逐步独立实现提示
使用两层循环写入 image.at<Vec3b>(y,x)[2]=10*x，其他通道设零。取得 ROI 后逐行 ptr<Vec3b>，再在每行累加第三通道。对 clone 重复同一循环，两个总和均应为 180。修改 ROI 一个像素后核对父图相同坐标，检查父图其他位置保持原值；clone 应不受后续修改影响。

## 调试提示与失败解释
错误实验：把 COLOR_BGR2GRAY 改成 COLOR_RGB2GRAY，同一存储得到约 18。这个错误不会导致异常，必须用人工构造的纯色点检查。HSV 的色相有环绕，8 位常规转换中红色会靠近色相区间的两端；用单一区间选择红色会漏掉一侧。
若数值不符，依次检查类型、坐标顺序、边界模式与参数；读取矩阵原值，不用显示归一化结果代替计算值。运行无效课号必须非零退出，输出路径错误也必须显式失败。
